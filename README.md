# SEO Rank Tracker

An AI-powered SEO Rank Tracker built using the MERN Stack. This application helps users analyze websites, monitor keyword rankings, and track SEO performance through a simple and interactive dashboard.

## 🚀 Tech Stack

- React.js
- TypeScript
- Vite
- Node.js
- Express.js
- MongoDB
- Mongoose

## 📌 Features

- Website SEO Analysis
- Keyword Rank Tracking
- SEO Dashboard
- Analysis History
- Report Generation
- User Authentication (In Progress)

## 📂 Project Structure

```
SEO-Rank-Tracker/
│
├── Client/
├── server/
└── README.md
```

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/pavankumarchoudari/SEO-Rank-Tracker.git
```

Install dependencies:

### Frontend

```bash
cd Client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run server
```
